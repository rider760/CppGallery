# Screenshot Placeholders

Use this directory for public-release screenshots referenced by the main `README.md`.

Suggested files:

- `gallery-overview.png`: the main tiled gallery view
- `zoom-view.png`: a zoomed single-image view
- `start-pinned-launcher.png`: Windows Start / Start menu pinned launcher example

Keep screenshots reasonably clean:

- avoid personal or sensitive local folder names
- avoid private images unless you want them public
- prefer representative UI states with readable text
